## Overview

A fork of scratchblocks that makes it easier to create mockups of block-based code, including blocks, categories and shapes that do not exist in Scratch. It is not merged back upstream.

The public global and package name is `mockblocks`. The text syntax is the scratchblocks syntax.

## Layout

- `index.js` builds the public API (`parse`, `render`, `renderMatching`, `newView`, `loadLanguages`, `stringify`). `browser.js` and `browser.es.js` are the bundle entry points.
- `syntax/` is the parser and model. `commands.js` is the list of known blocks, `blocks.js` turns it into lookup tables, `syntax.js` is the parser, `model.js` holds `Block`, `Input`, `Script` and friends.
- `scratch3/` is the renderer. It draws the Scratch 3 look in two styles, `scratch3` and `scratch3-high-contrast`. `draw.js` builds SVG paths, `blocks.js` lays blocks out, `style.css.js` holds the category colors. There is no Scratch 2 renderer; it was removed from the fork.
- `locales/` is generated by `npm run locales` from `scratch-l10n`. Do not edit the JSON by hand except for the `mockblocks:` ids.
- `tests/` has the Jest parser tests. `snapshots/` renders scripts to PNG with puppeteer.

## Commands

- `npm test` runs the Jest tests.
- `npm run snapshots` renders every snapshot script to PNG. Rendering differs slightly between machines, so compare against a render you made yourself on the same machine, not against the committed PNGs.
- `npm run build` writes `build/`. `npm start` serves the dev page at <http://localhost:8000/>.
- `npm run lint` and `npm run fmt`.

## Searching the Codebase

Use fast, modern tools instead of the slow defaults:

- [`rg`](https://github.com/BurntSushi/ripgrep) (ripgrep) for text search, not `grep`. It respects `.gitignore` for you. Prefer to use [`ast-grep`](https://ast-grep.github.io) when applicable as it uses the structure of the code instead.
- [`fd`](https://github.com/sharkdp/fd) for finding files by name, not `find`.
- [`ast-grep`](https://ast-grep.github.io) for structural searches and rewrites, like finding every call to a function or every component that uses a certain prop. Call it as `ast-grep`. The `sg` alias is deprecated, so don't use it.
- `jq` for reading and querying JSON.

If your harness has dedicated search or file tools that already wrap these, those are fine too.

## Keep things human

Do no use em dashes or other special symbols not normally found in writing. Do not word things in a weird way. Keep it looking human. If you need to use, for example, an arrow icon, use an SVG instead.

Replacing an em dash with a hyphen is NOT a fix. A spaced hyphen doing an em dash's job ("the limit - 4 bytes", "fast - but wrong") is the same tic with a different character. Reword the sentence instead: use a comma, a colon, parentheses, or the actual word ("minus", "to", "through"). Plain hyphens in compound words and numeric ranges like 0-1 are fine.

It's fine to be British in the chat if the person is actually in a region where its spelled like that. But if not just use American spelling. The tool itself MUST use American spelling.
